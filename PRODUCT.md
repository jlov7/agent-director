# Product

## Register

product

## Users

Agent builders, operators, and technical leads use Agent Director while investigating real AI-agent runs. They are usually trying to understand what happened, decide what to fix, and turn a failed or interesting run into repeatable release evidence.

## Product Purpose

Agent Director is an agent observability and improvement loop. It ingests traces, preserves provenance, surfaces causal evidence, creates eval cases, labels replay truthfully, and helps teams ship agent changes with current release gates rather than intuition.

## Brand Personality

Exacting, cinematic, technical. The interface should feel like a high-trust command surface for people who debug complex systems under pressure.

## Anti-references

Avoid generic SaaS dashboards, decorative card grids, neon AI-purple gradients, fake metrics, casual illustrations, marketing-page hero layouts, and UI that makes simulated replay look like live execution.

## Design Principles

- Evidence first: the strongest visual hierarchy belongs to trace provenance, failure state, eval status, replay truth, and release readiness.
- Product over theatre: visual drama must clarify investigation flow, not decorate it.
- Dense where useful, calm where decisions happen: operators should scan quickly without feeling buried.
- Truthful interaction: labels must distinguish recorded evidence, counterfactual simulation, and future executed replay.
- Accessible by default: keyboard, reduced motion, contrast, and readable copy are core workflow requirements.

## Accessibility & Inclusion

Target WCAG AA behavior on primary journeys. Preserve reduced-motion support, minimum 44px interactive targets, non-color status cues, clear focus states, and responsive layouts that avoid clipping or horizontal scroll.
