# 5-Minute Evaluator Quickstart

Goal: understand run quality and decision risk quickly.

## Minute 0-1: Enter Review
1. Open Agent Director with route shell enabled.
2. Select `Review` route.
3. If guided mode is active, click `Start first win`.

## Minute 1-3: First-Value Pass
1. Click `Review run health`.
2. Click `Inspect top risk`.
3. Confirm route outcome and progress strip.

## Minute 3-4: Confidence Check
1. Validate `Recent route actions`.
2. Confirm `Resume here` marker for current checkpoint.

## Minute 4-5: Executive Summary
1. Click `Share handoff digest`.
2. Copy/share digest with stakeholders.

## Success Criteria
- Run health reviewed.
- Top risk inspected.
- Clear handoff summary generated.
