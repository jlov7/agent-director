# Agent Director Overview Film Design

This film inherits the repository visual system from `../../../DESIGN.md`.

## Style Prompt

Create a command-grade observability proof film for Agent Director: carbon-black surfaces, warm technical borders, precise typography, and sparse signal color. The motion should feel like evidence becoming legible: traces align, warnings surface, evals lock, and replay truth is made explicit.

## Colors

- Canvas Carbon: `#05070b`
- Panel Carbon: `#0a111c`
- Warm Border: `rgba(126, 118, 105, 0.28)`
- Snow Text: `#f2f6f4`
- Steel Text: `#a9b6c9`
- Muted Telemetry: `#748399`
- Signal Emerald: `#2fd6a1`
- Signal Blue: `#6fb7ff`
- Warning Amber: `#f0c86d`
- Danger Coral: `#f07c82`

## Typography

- Display and interface headings: Space Grotesk.
- Trace IDs, timings, eval evidence, and gate labels: IBM Plex Mono.

## What NOT To Do

- No generic AI blob art.
- No purple/blue gradient-text SaaS styling.
- No mascot language, emoji, or fake metrics.
- No claim that simulated replay is live execution.
- No equal-weight three-card marketing grid.
