# 5-Minute Operator Quickstart

Goal: run a deterministic incident triage in under five minutes.

## Minute 0-1: Enter Triage
1. Open Agent Director with route shell enabled.
2. Select `Triage` route.
3. If guided mode is active, click `Start first win`.

## Minute 1-3: Execute Sequence
1. Click `Observe incident`.
2. Click `Isolate cause`.
3. Click `Validate fix`.
4. If blocked, open `Open support diagnostics` from triage recovery point.

## Minute 3-4: Handoff
1. Click `Share handoff`.
2. Confirm `Recent route actions` and `Resume here` marker in route history.

## Minute 4-5: Coordinate
1. Switch to `Coordinate` route.
2. Set `Run owner` and `Handoff owner`.
3. Click `Capture snapshot`.

## Success Criteria
- Triage sequence complete.
- Handoff digest copied/shared.
- Snapshot recorded for asynchronous responders.
